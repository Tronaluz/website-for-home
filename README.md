# Homewealth

![Logo Homewealth](./assets/images/logo.png)

Um protótipo de website moderno de imóveis projetado para ajudar usuários a encontrarem seu lar perfeito.

## Descrição

Homewealth é uma plataforma web que conecta pessoas com seus espaços ideais para viver. O site oferece funcionalidades para comprar, vender e alugar propriedades com uma interface intuitiva e responsiva.

## Funcionalidades

- **Busca de Propriedades**: Filtre por tipo de propriedade e localização
- **Múltiplas Opções**: Compre, venda ou alugue propriedades
- **Interface Amigável**: Design limpo e moderno com navegação intuitiva
- **Design Responsivo**: Otimizado para todos os tamanhos de dispositivos

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts (Montserrat)
- Ícones Material Symbols Rounded

1. Clone o repositório:

2. Abra o arquivo `index.html` no seu navegador para visualizar o projeto.
